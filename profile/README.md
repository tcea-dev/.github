# TCEA — Trusted Cognitive Execution Architecture

**A general transaction layer for AI agents.** Governed agent transactions with
signed intent, scoped authority, pre-execution policy admission, outcome
verification, and a portable, tamper-evident evidence record. Verifiable agent
payment is a special case; TCEA is the general layer.

- 📄 **Paper:** *The General Transaction Layer for AI Agents* — [10.5281/zenodo.24057182](https://doi.org/10.5281/zenodo.24057182)
- 📘 **Spec + runtimes + conformance:** the [`tcea`](https://github.com/tcea-dev/tcea) repository
